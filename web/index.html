Algorithmic Reference

Detailed mathematical specifications of core retrieval algorithms powering ContextRRF.

CORE ALGORITHM

1. Reciprocal Rank Fusion (RRF)

$$RRF(d) = \sum_{s \in S} \frac{w_s}{k + \text{rank}_s(d)}$$

Combines ranked candidate lists from multiple retrieval channels without requiring calibrated score normalization. $k=60$ dampens rank variance, while missing items receive penalty rank $|L_s| + 1$.

2. BM25 Scoring

$$BM25(q, d) = \sum_{t \in q} \text{IDF}(t) \cdot \frac{f(t, d) \cdot (k_1 + 1)}{f(t, d) + k_1 \cdot (1 - b + b \cdot \frac{|d|}{\text{avgdl}})}$$

Evaluates term frequency and inverse document frequency over code and text content using SQLite FTS5.

3. Sub-linear TF-IDF Vector Cosine

$$w_{t,d} = (1 + \ln(\text{tf}_{t,d})) \cdot \ln(1 + \frac{N}{\text{df}_t})$$

Calculates sparse tf-idf vector similarity over token n-grams to capture global term importance.

4. Value-Density Ranking

$$\text{Density}(d) = \frac{\text{Relevance}(d)}{1.0 + \ln(1 + \max(1, \text{Tokens}))}$$

Balances relevance score against chunk token size using logarithmic dampening to favor compact, information-dense code blocks.
